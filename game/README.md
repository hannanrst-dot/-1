# کارگاه ماشین‌های ساده

> آزمایشگاه تعاملی «ماشین‌های ساده» برای درس علوم تجربی پایهٔ پنجم دبستان
> — اهرم، قرقره، سطح شیب‌دار، چرخ و محور، گوه، پیچ و چرخ‌دنده.

یک برنامهٔ وب کاملاً خودکفا (بدون سرور، بدون کتابخانهٔ بیرونی، بدون نیاز به اینترنت)
که در آن دانش‌آموز به‌جای خواندن دربارهٔ ماشین‌های ساده، آن‌ها را **می‌سازد، تنظیم می‌کند و اندازه می‌گیرد**.

---

## چه چیزی در آن هست؟

### ۸ ماشین ساده با فیزیک واقعی

| ماشین | چه چیزی را می‌شود تغییر داد | چه چیزی آموزش داده می‌شود |
|---|---|---|
| اصطکاک، چرخ و غلتک | جرم، جنس سطح، غلتک، مسافت | اصطکاک لغزشی در برابر غلتشی |
| سطح شیب‌دار | ارتفاع، طول رمپ، جنس رویه، غلتک | دادوستد نیرو و مسافت |
| اهرم | طول تیرک، جای تکیه‌گاه و بار، ارتفاع بلند کردن | تعادل گشتاور، سه نوع اهرم |
| قرقره | ۶ سامانه از «بدون قرقره» تا «مرکب ۴ رشته‌ای» | شمردن رشته‌های نگهدارندهٔ بار |
| چرخ و محور | شعاع چرخ، شعاع محور، عمق چاه | اهرمِ چرخان |
| گوه | سرسختی چوب، طول و ضخامت گوه | سطح شیب‌دارِ متحرک |
| پیچ | گام پیچ، شعاع دسته، ارتفاع | سطح شیب‌دارِ پیچیده‌شده |
| چرخ‌دنده | تعداد دندانه‌ها، گشتاور و سرعت ورودی | دادوستد سرعت و گشتاور |

هر آزمایش این اعداد را زنده گزارش می‌کند: **نیروی لازم، وزن بار، مزیت مکانیکی،
مسافت کشیدن، کار و بازده** — و «کارِ ورودی» هیچ‌وقت از «کار مفید» کمتر نمی‌شود
(پایستگی انرژی با تست تضمین شده است).

### دو حالت کار

- **مأموریت‌ها** — ۹ مأموریت داستانی (یکی برای هر ماشین + یک مأموریت پایانیِ ترکیبی).
  هر مأموریت با یک پرسشِ پیش‌بینی شروع می‌شود، سه پله راهنمایی دارد و با باز شدن یک
  «کارت کشف علمی» تمام می‌شود.
- **آزمایشگاه** — همهٔ متغیرها آزادند. جدول اندازه‌گیری، نمودار زندهٔ نیرو بر حسب هر
  پارامتر، و انتخاب اینکه «چه کسی نیرو وارد می‌کند» (دانش‌آموز، بزرگ‌سال، دو نفر).

### برای آموزگار و اولیا

- انطباق با اهداف برنامهٔ درسی + پیشنهادهای کلاسی
- کارنامهٔ دانش‌آموز و «دفترچهٔ مخترع» قابل چاپ یا ذخیره به‌صورت PDF

### دسترسی‌پذیری

سه تم (روشن، تیره، کنتراست بالا) • کاهش انیمیشن • زیرنویس صداها •
توضیح متنی صحنه برای صفحه‌خوان • میان‌برهای صفحه‌کلید:

| کلید | کار |
|---|---|
| `فاصله` | اجرای آزمایش |
| `R` | از نو |
| `H` | راهنمایی بعدی |
| `V` | نمایش بردارهای نیرو |
| `M` | بی‌صدا |
| `۱`…`۹` | رفتن به مأموریت یا ماشین |
| `Esc` | بستن پنجره |

## اجرا

```bash
# ۱) ساده‌ترین راه: فایل تک‌فایلیِ آماده را در مرورگر باز کنید
open dist/kargah-mashinhaye-sadeh.html

# ۲) یا نسخهٔ ماژولار را با یک سرور محلی اجرا کنید
npm start          # روی http://localhost:8080
```

> نسخهٔ ماژولار از ES Modules استفاده می‌کند و باید از طریق `http://` باز شود،
> نه با دوبار کلیک روی `index.html` (به‌خاطر محدودیت `file://` در مرورگرها).
> برای اجرای آفلاین در کلاس، فایل `dist/kargah-mashinhaye-sadeh.html` را ببرید —
> همه‌چیز از جمله فونت داخل خودش است.

## تست و ساخت

```bash
npm test     # ۲۷ تست: درستی فرمول‌ها، پایستگی انرژی و حل‌شدنی بودن مأموریت‌ها
npm run build   # ساخت نسخهٔ تک‌فایلی در dist/
```

## چند نکتهٔ فنی

- **فیزیک از رابط کاربری جداست.** ماژول `physics/` هیچ وابستگی‌ای به DOM ندارد و
  مستقیماً با `node --test` آزموده می‌شود.
- **کنترل‌ها اعلانی‌اند.** هر ماشین فهرستی از لغزنده/دکمه/کلید را توصیف می‌کند و
  هم آزمایشگاه و هم مأموریت‌ها از همان توصیف ساخته می‌شوند.
- **هندسهٔ صحنه‌ها واقعی است.** مقیاس متر به پیکسل حساب می‌شود، پس زاویهٔ رمپ،
  چرخش اهرم حول تکیه‌گاه و مسیر طنابِ هر سامانهٔ قرقره با اعداد فیزیک هم‌خوان است.
- **بدون وابستگی بیرونی.** نه کتابخانه، نه CDN، نه فایل صوتی؛ صداها با Web Audio
  ساخته می‌شوند و فونت داخل مخزن است.
