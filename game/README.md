# آزمایشگاه ماشین‌های ساده

> ابزار تدریس و اندازه‌گیری برای درس علوم تجربی — اهرم، قرقره، سطح شیب‌دار،
> چرخ و محور، گوه، پیچ، چرخ‌دنده و اصطکاک.

این یک بازی نیست؛ یک **میز آزمایش دیجیتال** است. آموزگار هر ماشین ساده را با
اعداد واقعی می‌سازد، حرکت را اجرا می‌کند و نتیجه را هم‌زمان در سه سطح می‌بیند:

1. **نمای صحنه** — با خط‌های اندازه، زاویه، بردارهای نیرو و نیروسنجِ روی طناب
2. **جدول اندازه‌گیری** — نیرو، مزیت مکانیکی، مسافت‌ها، کار و بازده با نماد و یکا
3. **محاسبهٔ گام‌به‌گام** — همان چیزی که روی تخته می‌نویسید: فرمول، جای‌گذاری اعداد، نتیجه

همهٔ اعداد از یک موتور فیزیک واحد می‌آیند. هیچ عددی دستی نوشته نشده و همه با تست
بررسی می‌شوند.

## هشت ماشین ساده

| ماشین | متغیرهای قابل تنظیم | رابطهٔ اصلی |
|---|---|---|
| اصطکاک، چرخ و غلتک | جرم، جنس سطح، غلتک، مسافت | `f = μ × F_w` |
| سطح شیب‌دار | ارتفاع، طول رمپ، جنس رویه، غلتک | `MA₀ = L ÷ h` |
| اهرم | طول تیرک، جای تکیه‌گاه و بار، ارتفاع بلند شدن | `F_w × d_w = F × d_F` |
| قرقره | شش سامانه از «بدون قرقره» تا «مرکب ۴ رشته‌ای» | `F = F_w ÷ n` |
| چرخ و محور | شعاع چرخ، شعاع محور، عمق چاه | `MA₀ = R ÷ r` |
| گوه | نیروی مقاوم، طول و ضخامت گوه | `MA₀ = L ÷ t` |
| پیچ | گام پیچ، شعاع دسته، ارتفاع | `MA₀ = 2πR ÷ p` |
| چرخ‌دنده | تعداد دندانه‌ها، گشتاور و سرعت ورودی | `i = z₂ ÷ z₁` |

## دو کلیدی که برای تدریس ساخته شده‌اند

- **شتاب گرانش g** — جابه‌جایی بین مقدار کتاب درسی (۱۰) و مقدار واقعی (۹٫۸۱).
- **اصطکاک: واقعی / آرمانی** — با یک کلیک همهٔ اصطکاک‌ها صفر می‌شوند تا تفاوت
  «مزیت مکانیکی آرمانی» و «واقعی» و معنای بازده مقابل چشم دانش‌آموز روشن شود.

## کارهای دیگر

- **اجرای حرکت** با شمارندهٔ زندهٔ «بار چقدر جابه‌جا شد» و «ما چقدر مسافت رفتیم» —
  کلید فهم دادوستد نیرو و مسافت.
- **کشیدن روی تصویر**: تکیه‌گاه اهرم و بالای رمپ را می‌شود مستقیم با ماوس جابه‌جا کرد.
- **ثبت اندازه‌گیری** برای مقایسهٔ چند تنظیم کنار هم + نمودار زندهٔ نیرو بر حسب هر پارامتر.
- **گزارش قابل چاپ** شامل محاسبهٔ گام‌به‌گام، نتیجه، جدول ثبت‌شده‌ها و جای نتیجه‌گیری دانش‌آموز.
- ورودی‌های عددی با ارقام فارسی؛ می‌توانید مقدار دقیق را تایپ کنید، نه فقط با لغزنده.

## دسترسی‌پذیری

تم روشن/تیره (پیرو تنظیم سیستم) • توضیح متنی صحنه برای صفحه‌خوان •
کاهش انیمیشن • میان‌برها: `فاصله` اجرا، `R` بازنشانی، `V` بردارها، `D` خط‌های اندازه،
`۱`…`۸` انتخاب ماشین، `Esc` بستن.

## اجرا

```bash
# ساده‌ترین راه — یک فایل مستقل، بدون نیاز به اینترنت یا سرور
open dist/azmayeshgah-mashinhaye-sadeh.html

# یا نسخهٔ ماژولار با سرور محلی
npm start        # http://localhost:8080
```

> نسخهٔ ماژولار از ES Modules استفاده می‌کند و باید از `http://` باز شود.
> برای کلاس، همان فایل تک‌فایلی را ببرید؛ فونت هم داخل خودش است.

```bash
npm test         # ۲۲ تست: فرمول‌ها، پایستگی انرژی، حالت آرمانی، کرانهٔ لغزنده‌ها
npm run build    # ساخت نسخهٔ تک‌فایلی
```

## چند نکتهٔ فنی

- **فیزیک از رابط جداست**: `src/physics/` هیچ وابستگی‌ای به DOM ندارد و مستقیم آزموده می‌شود.
- **هندسهٔ صحنه‌ها واقعی است**: مقیاس متر→پیکسل حساب می‌شود، پس زاویهٔ رمپ، چرخش اهرم
  حول تکیه‌گاه و مسیر طناب هر سامانهٔ قرقره با اعداد جدول هم‌خوان است.
- **بدون وابستگی بیرونی**: نه کتابخانه، نه CDN.
