# ثبت‌یار — نرم‌افزار فروشگاهی و مدیریت فروش فارسی (با قابلیت صوتی)

نرم‌افزاری ساده، سریع و کاربردی برای مدیریت فروشگاه با تمرکز بر سه چیز:
**ثبت و مدیریت کالا**، **صدور سریع فاکتور**، و **انجام عملیات با صدای فارسی**.

رابط کاربری کاملاً فارسی، راست‌چین (RTL)، با اعداد فارسی، تاریخ شمسی، طراحی
مینیمال، دکمه‌های بزرگ، دارک‌مود و ریسپانسیو کامل (کامپیوتر/تبلت/موبایل).

معماری از ابتدا ماژولار و قابل‌توسعه طراحی شده تا بدون بازنویسی اساسی بتوان
امکانات جدید (حسابداری، چند فروشگاه، درگاه پرداخت، …) اضافه کرد، و به‌گونه‌ای
که وابسته به هیچ سرویس خارجیِ اجباری نباشد و روی **هاست‌های ایرانی** اجرا شود.

## معماری پروژه

```
┌─────────────────────────────────────────────────────────────┐
│                      مرورگر (Frontend)                        │
│   SPA سبک، Vanilla JS، بدون build-step، RTL، دارک‌مود        │
│   + نیمهٔ مرورگری موتور صوتی (Web Speech API)                 │
└───────────────┬─────────────────────────────────────────────┘
                │  HTTP/JSON  (/api/*)
┌───────────────▼─────────────────────────────────────────────┐
│                    Node.js + Express (Backend)               │
│  ماژول‌ها: auth, products, invoices, purchases, inventory,   │
│           customers, suppliers, reports, settings, backup,   │
│           voice                                              │
│  ┌─────────────── Voice Engine (مستقل) ─────────────────┐    │
│  │ Normalizer → Intent → Entities → Matcher → Validation │   │
│  │  → پرسش رفع ابهام → تأیید → (اجرا در ماژول‌های تجاری)  │   │
│  └───────────────────────────────────────────────────────┘  │
└───────────────┬─────────────────────────────────────────────┘
                │  Repository / SQL
┌───────────────▼─────────────────────────────────────────────┐
│              SQLite (تک‌فایل، قابل انتقال، Backup آسان)       │
└─────────────────────────────────────────────────────────────┘
```

**اصول کلیدی:**
- **Backend استاندارد** (Node/Express) و **Database استاندارد** (SQLite تک‌فایل).
- تمام تنظیمات مهم از طریق **Environment Variables** (فایل `.env`).
- APIهای ماژولار و مستند؛ هر بخش تجاری در پوشهٔ مستقل خودش.
- موتور صوتی کاملاً جدا و پشت **Interface قابل‌تعویض** — تشخیص گفتار در مرورگر
  انجام می‌شود و در آینده می‌توان با تغییر یک متغیر محیطی موتور دیگری جایگزین کرد.
- **امنیت عملیات مالی:** تشخیص صوتی هرگز مستقیماً عملیات را اجرا نمی‌کند؛ همیشه
  مسیرِ «تفسیر → پرسش رفع ابهام → نمایش نتیجه → تأیید کاربر → اجرا» طی می‌شود.

جزئیات بیشتر در [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md).

## نصب و اجرا (محلی)

```bash
# ۱) نصب وابستگی‌ها
npm install

# ۲) ساخت فایل تنظیمات و ویرایش آن (به‌ویژه SESSION_SECRET)
cp .env.example .env

# ۳) مقداردهی اولیهٔ دیتابیس (ساخت کاربر مدیر + داده‌های نمونه)
npm run seed

# ۴) اجرا
npm start
```

سپس در مرورگر باز کنید: `http://localhost:3000`

ورود پیش‌فرض: نام کاربری `admin` — رمز `admin`
(بلافاصله از بخش «تنظیمات ← کاربران» رمز را عوض کنید.)

دستورهای مفید:

```bash
npm run dev         # اجرا با ری‌استارت خودکار هنگام تغییر کد
npm run reset-db    # پاک‌سازی کامل و ساخت مجدد دیتابیس نمونه
npm run backup      # ساخت پشتیبان از خط فرمان
```

## موتور صوتی چگونه کار می‌کند

مسیر امن پردازش صدا دقیقاً مطابق طراحی خواسته‌شده است:

```
صدای کاربر (مرورگر)
  → تبدیل به متن            (Web Speech API — fa-IR)
  → نرمال‌سازی فارسی        (server/voice/normalizer.js)
  → تشخیص دستور (Intent)    (server/voice/intent.js)
  → استخراج اطلاعات         (server/voice/entities.js + numbers.js)
  → تطبیق هوشمند کالا        (server/voice/matcher.js)
  → بررسی صحت و در صورت ابهام پرسش از کاربر
  → نمایش نتیجه و گرفتن تأیید
  → اجرای عملیات در ماژول تجاری مربوطه
  → دیتابیس
```

نمونه‌ها:

- **ثبت کالا:** «دفتر پاپکو ۸۰ برگ، تعداد ۵۰ تا، قیمت خرید ۴۵ هزار تومان، قیمت فروش ۶۰ هزار تومان»
- **فاکتور:** «برای علی رضایی سه تا دفتر پاپکو و دو تا مداد استدلر بزن»
- **خرید:** «از شرکت پاپکو ۱۰۰ تا دفتر خریدم، قیمت خرید هرکدام ۴۵ هزار تومان»
- **پرسش:** «فروش امروز چقدر بوده؟» / «کدوم کالاها موجودیشون کمه؟»

نرمال‌ساز، تفاوت‌های نگارشی (ی/ي، ک/ك)، اعداد فارسی/انگلیسی، و شکل‌های مختلف بیان
عدد و قیمت (۵۰ هزار / پنجاه هزار / ۵۰ تومن / ۵۰۰۰۰) را مدیریت می‌کند.

**تعویض موتور تشخیص گفتار در آینده:** کافی است یک recognizer جدید در
`server/voice/recognizers.js` ثبت کنید و متغیر `VOICE_RECOGNIZER` را در `.env`
تغییر دهید. بدنهٔ اپ نیاز به تغییر ندارد.

## مستندات API

همهٔ APIها با پیشوند `/api` و خروجی JSON استاندارد `{ ok: true/false, ... }`.
فهرست کامل در [`docs/API.md`](docs/API.md). خلاصه:

| گروه | نمونه Endpoint |
|------|----------------|
| احراز هویت | `POST /api/auth/login` · `GET /api/auth/me` · `POST /api/auth/users` |
| کالا | `GET/POST /api/products` · `PUT /api/products/:id` · `POST /api/products/:id/adjust-stock` |
| فاکتور | `GET/POST /api/invoices` · `GET /api/invoices/:id` |
| خرید | `GET/POST /api/purchases` |
| مشتری/تأمین‌کننده | `GET/POST /api/customers` · `GET/POST /api/suppliers` |
| گزارش | `GET /api/reports/dashboard` · `/sales-daily` · `/profit` · `/debts` |
| صوتی | `POST /api/voice/interpret` · `POST /api/voice/query` |
| پشتیبان | `GET/POST /api/backup` · `GET /api/backup/download/:name` |

## پشتیبان‌گیری و بازیابی

چون دیتابیس یک **فایل مستقل SQLite** است، پشتیبان‌گیری و انتقال بسیار ساده است:

- از داخل برنامه: **تنظیمات ← پشتیبان‌گیری ← ساخت پشتیبان جدید** (سپس دانلود فایل).
- از خط فرمان: `npm run backup`
- **بازیابی:** فایل پشتیبان (`.db`) را جایگزین `data/store.db` کنید و برنامه را ری‌استارت نمایید.

## استقرار روی هاست ایرانی

این پروژه به هیچ سرویس ابری خارجی وابسته نیست و روی هاست‌های معمولی قابل اجراست.

### الف) هاست/سرور با پشتیبانی Node.js (VPS یا cPanel با «Setup Node.js App»)

۱. فایل‌های پروژه را آپلود کنید (پوشهٔ `node_modules` را آپلود نکنید).
۲. `.env` را بسازید و مقداردهی کنید — حتماً:
   - `NODE_ENV=production`
   - `SESSION_SECRET` را به یک رشتهٔ تصادفی طولانی تغییر دهید.
   - در صورت نیاز `PORT` را مطابق هاست تنظیم کنید.
۳. دستورها:
   ```bash
   npm install --omit=dev
   npm run seed        # فقط بار اول
   npm start
   ```
   در cPanel: «Application Startup File» را `server/index.js` و «Application Mode»
   را `production` بگذارید؛ سپس `npm install` و Run را از پنل بزنید.

۴. برای اجرای دائمی روی VPS از **pm2** استفاده کنید:
   ```bash
   npm install -g pm2
   pm2 start server/index.js --name sabtyar
   pm2 save && pm2 startup
   ```

۵. توصیه می‌شود پشت **Nginx** با HTTPS قرار دهید (Web Speech API فقط روی
   `https://` یا `localhost` فعال می‌شود). نمونهٔ ساده:
   ```nginx
   server {
     server_name shop.example.ir;
     location / { proxy_pass http://127.0.0.1:3000; proxy_set_header Host $host; }
   }
   ```

### ب) نکتهٔ `better-sqlite3`

این پکیج هنگام `npm install` روی خود سرور کامپایل می‌شود و به ابزارهای ساخت
(`python`, `make`, `g++`) نیاز دارد که روی اغلب هاست‌ها موجود است. اگر هاست شما
اجازهٔ کامپایل نمی‌دهد، `npm install` را روی سیستمی با همان معماری/نسخهٔ Node انجام
دهید و پوشهٔ `node_modules` را نیز آپلود کنید.

### پشتیبان‌گیری خودکار (اختیاری)

یک cron روزانه اضافه کنید:
```
0 2 * * * cd /path/to/app && npm run backup
```

## توسعه در آینده

معماری به‌گونه‌ای است که موارد زیر بدون بازنویسی قابل افزودن‌اند:
حسابداری، مدیریت چک و بدهی، باشگاه مشتریان، تخفیف‌های پیشرفته، فروش آنلاین و درگاه
پرداخت، مدیریت چند فروشگاه/چند انبار، اپلیکیشن موبایل، گزارش‌های پیشرفته، و
دستیار صوتی کامل‌تر (با جایگزینی موتور STT پشت همان Interface موجود).

برای افزودن یک ماژول جدید کافی است پوشه‌ای در `server/modules/` بسازید، یک Router
اکسپرس بنویسید و آن را در `server/index.js` ثبت کنید. جداول جدید را به `schema.sql`
اضافه کنید (طراحی فعلی مانع افزودن جدول نیست).
