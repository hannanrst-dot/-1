# ثبت‌یار — نرم‌افزار فروشگاهی و مدیریت فروش فارسی (با دستیار صوتی)

نرم‌افزار مدیریت فروشگاه با رابط کاربری کاملاً فارسی و راست‌چین، تاریخ شمسی،
دارک‌مود، و **دستیار صوتی هوشمند فارسی** برای ثبت سریع کالا، فاکتور و خرید.

- **فرانت‌اند/بک‌اند:** Next.js 16 + React 19 + TypeScript + Tailwind
- **دیتابیس:** SQLite تک‌فایل (بدون نیاز به سرویس دیتابیس جداگانه — مناسب هاست ایرانی)
- **موتور صوتی:** تشخیص گفتار مرورگر (Web Speech API) + پردازش زبان طبیعی فارسی روی سرور

> ورود پیش‌فرض: کاربری `admin` — رمز `admin123`

---

## اجرای محلی

```bash
npm install
npm run dev        # اجرای حالت توسعه روی http://localhost:3000
# یا برای اجرای تولیدی:
npm run build && npm start
```

دیتابیس در اولین اجرا به‌صورت خودکار در `data/store.db` ساخته و با داده‌های نمونه
(کاربر مدیر، چند کالا و مشتری) پر می‌شود؛ نیازی به دستور جداگانه نیست.

## دستیار صوتی

روی دکمهٔ میکروفون بزنید و شروع به صحبت کنید. **شروع و توقف ضبط کاملاً با شماست**:
هر چقدر می‌خواهید بگویید، سپس روی همان دکمه بزنید تا ضبط متوقف و نتیجه ساخته شود.

می‌توانید همه‌چیز را در **یک گفتار** بگویید:

- **فاکتور:** «برای علی رضایی سه تا دفتر پاپکو و دو تا مداد استدلر و یک پاک‌کن فابر بزن»
- **ثبت کالا:** «دفتر پاپکو ۸۰ برگ، تعداد ۵۰ تا، قیمت خرید ۴۵ هزار، قیمت فروش ۶۰ هزار»
- **خرید:** «از شرکت پاپکو صد تا دفتر خریدم دونه‌ای چهل و پنج هزار»
- **پرسش:** «فروش امروز چقدر بوده؟» / «کدوم کالاها موجودیشون کمه؟»

مسیر امن پردازش: صدا → متن → تحلیل → استخراج اطلاعات → تطبیق هوشمند کالا →
پرسش در صورت ابهام → **نمایش پیش‌نمایش و تأیید کاربر** → ثبت در دیتابیس.
هیچ عملیات مالی بدون تأیید شما انجام نمی‌شود.

نکتهٔ مهم: تشخیص گفتار مرورگر فقط روی `https://` یا `localhost` فعال می‌شود.

## استقرار روی لیارا (Liara)

این نرم‌افزار به دیتابیس جداگانه نیاز ندارد و روی پلتفرم Next.js لیارا بالا می‌آید.

```bash
npm install -g @liara/cli
liara login
# داخل پوشه پروژه:
liara deploy --app نام-برنامه-شما --port 3000
```

در کنسول لیارا، هنگام ساخت برنامه حتماً پلتفرم را **Next.js** انتخاب کنید.
پس از استقرار، آدرسی مثل `https://نام-برنامه.liara.run` می‌گیرید و با
`admin` / `admin123` وارد می‌شوید.

### ماندگاری دائمی اطلاعات (برای استفادهٔ واقعی)

فضای فایل برنامه روی لیارا فقط‌خواندنی است؛ برنامه به‌طور خودکار دیتابیس را در
یک مسیر موقت می‌سازد تا حتماً بالا بیاید، اما این مسیر با هر ری‌استارت پاک می‌شود.
برای اینکه اطلاعات شما همیشه بماند:

1. در کنسول لیارا، بخش **دیسک‌ها** → دیسک جدید با نام `data` و مسیر `/app/data`.
2. در بخش **متغیرها (Environment Variables)** مقدار زیر را اضافه کنید:
   `DATABASE_FILE=/app/data/store.db`
3. برنامه را یک‌بار ری‌استارت کنید.

فایل کامل راهنما نیز داخل خود برنامه (تنظیمات ← راهنمای استقرار) موجود است.

## ساختار پروژه

```
src/
├── app/                 # صفحات و API Routeهای Next.js (App Router)
│   ├── api/             # auth, products, invoices, purchases, voice, reports, ...
│   ├── products/ invoices/ customers/ suppliers/ reports/ settings/ ...
├── components/          # کامپوننت‌ها (layout, voice, invoice, barcode, ...)
├── context/             # AuthContext, ThemeContext
├── db/
│   ├── schema.ts        # اسکیمای SQLite (Drizzle ORM)
│   └── index.ts         # اتصال دیتابیس + انتخاب مسیر قابل‌نوشتن + ساخت جداول
├── lib/
│   ├── voice/           # موتور صوتی: نرمال‌ساز، تشخیص Intent، تطبیق کالا
│   ├── persian/         # ابزارهای فارسی (اعداد، تاریخ شمسی، شباهت متن)
│   ├── auth/            # نشست
│   └── db/seed.ts       # داده‌های اولیه/نمونه
└── instrumentation.ts   # مقداردهی خودکار دیتابیس هنگام راه‌اندازی سرور
```
