# آیفون سنتر — فروشگاه اینترنتی آیفون تصویری و دربازکن

فروشگاه اینترنتی کامل و چندفروشندگی برای عرضه آیفون تصویری، آیفون صوتی، پنل ورودی،
قفل برقی، جک درب پارکینگ، دوربین مداربسته و لوازم جانبی.

ساخته‌شده با **Next.js 15 (App Router) + TypeScript + Tailwind CSS + Prisma/SQLite**،
کاملاً فارسی و راست‌چین.

---

> برای انتشار روی سرور، فایل [`DEPLOY-LIARA.md`](./DEPLOY-LIARA.md) را ببینید.

## راه‌اندازی سریع

```bash
npm install          # نصب وابستگی‌ها
cp .env.example .env # تنظیم متغیرها (در حالت توسعه از پیش آماده است)
npm run setup        # ساخت دیتابیس + داده‌های نمونه
npm run dev          # اجرا روی http://localhost:3000
```

> اگر پورت ۳۰۰۰ اشغال باشد، Next.js خودش پورت بعدی (۳۰۰۱) را انتخاب می‌کند؛
> آدرس دقیق در خروجی ترمینال نوشته می‌شود.

برای اجرای نسخه نهایی:

```bash
npm run build
npm start            # دیتابیس را می‌سازد، در صورت خالی بودن پر می‌کند و سرور را بالا می‌آورد
```

`npm start` هوشمند است: اگر دیتابیس از قبل داده داشته باشد، داده‌های نمونه را
دوباره نمی‌سازد و اطلاعات واقعی شما دست‌نخورده می‌ماند.

### متغیرهای محیطی

| متغیر | توضیح |
|---|---|
| `DATABASE_URL` | آدرس دیتابیس (پیش‌فرض SQLite: `file:./dev.db`) |
| `AUTH_SECRET` | کلید امضای توکن نشست — **حتماً در سرور واقعی تغییر دهید** |

## امکانات

### فروشگاه (بخش عمومی)
- صفحه اصلی با اسلایدر، دسته‌بندی‌ها، پیشنهاد شگفت‌انگیز، پرفروش‌ترین‌ها و راهنمای خرید
- جستجوی زنده با پیشنهاد لحظه‌ای در هدر
- صفحه دسته‌بندی و جستجو با فیلترهای تخصصی:
  محدوده قیمت، برند، اندازه صفحه نمایش، نوع اتصال (۲/۴ سیمه، Wi-Fi)،
  حافظه‌دار، موجود، تخفیف‌دار، حداقل امتیاز — به‌همراه ۶ نوع مرتب‌سازی
- صفحه محصول: گالری تصاویر با بزرگ‌نمایی، انتخاب رنگ/مدل، جدول مشخصات فنی،
  نمودار امتیازها، دیدگاه کاربران با نقاط قوت و ضعف، پرسش و پاسخ، کالاهای مشابه
- سبد خرید با ذخیره‌سازی محلی، کد تخفیف، محاسبه ارسال رایگان
- تسویه حساب: مدیریت آدرس، انتخاب روش ارسال، پرداخت اینترنتی/در محل، سفارش خدمات نصب
- ویترین اختصاصی هر فروشنده
- صفحات درباره ما، تماس، نصب و راه‌اندازی، برندها، راهنماها و قوانین

### پنل کاربر
پیشخوان آماری، سفارش‌های من با نوار پیشرفت وضعیت، جزئیات سفارش و صورتحساب،
دفترچه آدرس، علاقه‌مندی‌ها، ویرایش پروفایل و تغییر رمز عبور

### پنل فروشنده
- ثبت‌نام فروشندگی با فرم اطلاعات کسب‌وکار و پیگیری وضعیت درخواست
- داشبورد: درآمد کل، تعداد فروش، تعداد محصولات و موارد در انتظار تأیید
- **بارگذاری محصول** در سه گام: اطلاعات اصلی (تصاویر چندگانه، قیمت، تخفیف، موجودی)،
  مشخصات فنی (ویژگی‌های تخصصی + جدول مشخصات با افزودن سریع)، و تنوع محصول (رنگ/مدل با موجودی مستقل)
- فهرست محصولات با فیلتر وضعیت، ویرایش، حذف و مشاهده دلیل رد شدن
- مدیریت سفارش‌ها و تغییر مرحله‌به‌مرحله وضعیت ارسال

### پنل مدیریت
داشبورد درآمد و آمار، تأیید/رد محصولات با ثبت دلیل، تأیید فروشندگان،
مدیریت سفارش‌ها و کد رهگیری، مدیریت کاربران و نقش‌ها، دسته‌بندی‌ها و کدهای تخفیف

## نکات فنی

- **احراز هویت**: JWT امضاشده با `jose` در کوکی `httpOnly`، رمزها با `bcrypt` هش می‌شوند.
- **امنیت قیمت**: قیمت سفارش همیشه سمت سرور از دیتابیس محاسبه می‌شود و هرگز از کلاینت پذیرفته نمی‌شود.
- **گردش تأیید**: هر محصول جدید یا ویرایش‌شده با وضعیت `PENDING` ثبت می‌شود و تا تأیید مدیر در سایت دیده نمی‌شود.
- **حذف امن**: محصولی که سابقه سفارش دارد حذف نمی‌شود، بلکه غیرفعال می‌شود تا تاریخچه سفارش‌ها سالم بماند.
- **نشانی محصولات**: عنوان فارسی به‌صورت خودکار به لاتین تبدیل می‌شود تا آدرس‌ها امن و قابل اشتراک باشند.
- **تاریخ شمسی**: تبدیل میلادی به جلالی بدون وابستگی خارجی انجام می‌شود.
- **تصاویر**: بارگذاری در `public/uploads` با محدودیت ۵ مگابایت و بررسی نوع فایل.

### تغییر اطلاعات فروشگاه
نام، شعار، تلفن، آدرس، ایمیل، شبکه‌های اجتماعی، آستانه ارسال رایگان و هزینه نصب
همگی در فایل `src/lib/site.ts` قرار دارند.

### انتقال به دیتابیس دیگر (PostgreSQL/MySQL)
در `prisma/schema.prisma` مقدار `provider` را تغییر دهید، `DATABASE_URL` را به‌روزرسانی
کنید و `npx prisma db push` را اجرا کنید.
