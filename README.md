# 🎮 بازی‌های ریاضی و علوم دبستان

بازی‌های تعاملی برای **فهمیدن** مفاهیم کتاب درسی — نه امتحان‌گرفتن.
هر بازی روی یک مفهوم اصلی ساخته شده و بچه با دست خودش آن را کشف می‌کند:
می‌بُرد، می‌چیند، می‌کشد، هُل می‌دهد و نتیجه را می‌بیند.

---

## راه‌اندازی

هیچ وابستگی‌ای لازم نیست — فقط Node.js نسخه‌ی ۱۸ به بالا:

```bash
node server.js
```

بعد در مرورگر برو به: **http://localhost:3000**

برای عوض‌کردن پورت:

```bash
PORT=8080 node server.js
```

## بازی‌های آماده

| بازی | پایه | درس | مفهوم اصلی |
|---|---|---|---|
| 🍕 **کارگاه کسر** | سوم | ریاضی، فصل ۳ | مخرج = به چند قسمت مساوی بریدیم، صورت = چند تا برداشتیم. کسرهای مساوی خودشان روی محور اعداد لو می‌روند. |
| 🏙️ **شهر عددها** | سوم | ریاضی، فصل ۲ | ارزش مکانی و «بستن ده‌تایی». آبشار ۱۹۹۹ ← ۲۰۰۰ را جلوی چشم می‌بیند. |
| 🧲 **آزمایشگاه آهن‌ربا** | سوم | علوم، درس ۱۰ | جذب فقط مواد آهنی، دفع و جذب قطب‌ها، و دیدن میدان با براده‌ی آهن. |

هر بازی چند «مرحله» یا «ایستگاه» دارد و پیشرفت بچه در مرورگر خودش ذخیره می‌شود.

## اضافه‌کردن بازی جدید

۱. یک پوشه بساز: `public/games/grade3/math/<اسم-بازی>/`
۲. داخلش `index.html` و `game.js` بگذار (از یکی از بازی‌های موجود الگو بگیر).
۳. در `data/games.json` یک ورودی اضافه کن؛ صفحه‌ی خانه خودش کارت آن را می‌سازد.

موتور مشترک این‌ها را آماده می‌دهد:

```js
import { faNum, Loop, Particles, sfx, celebrate, setHint, store } from '/assets/js/engine.js';
```

- `faNum(۱۲۳)` → رقم فارسی
- `new Loop(dt => …)` → حلقه‌ی انیمیشن
- `new Particles(canvas)` → کاغذرنگی، درخشش، حلقه‌ی موج
- `sfx.good() / sfx.pop() / sfx.nope()` → صدا، بدون هیچ فایل صوتی
- `celebrate({...})` → پرده‌ی جشن پایان مرحله
- `store.get/set` → ذخیره‌ی پیشرفت در مرورگر

## اصولی که در طراحی این بازی‌ها رعایت شده

- **بازی، نه آزمون.** هیچ‌جا «گزینه‌ی درست را انتخاب کن» نداریم.
- **اشتباه مجازات ندارد.** اشتباه فقط نتیجه‌ی دیگری نشان می‌دهد تا بچه خودش بفهمد چرا.
- **مفهوم دیدنی است.** ارزش مکانی با بلوک، کسر با برش، میدان با براده‌ی آهن.
- **هر چیزی که روی صفحه است، تعاملی است.** بچه چیزی را جابه‌جا یا عوض می‌کند و بلافاصله اثرش را می‌بیند.
- **فارسی و راست‌چین**، با رقم‌های فارسی، و قابل استفاده روی موبایل و تبلت با لمس.
