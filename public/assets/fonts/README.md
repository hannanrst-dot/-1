# فونت

اگر می‌خواهی سایت بدون اینترنت هم فونت وزیرمتن را داشته باشد،
این سه فایل را از https://github.com/rastikerdar/vazirmatn بردار
و همین‌جا بگذار:

- `Vazirmatn-Regular.woff2`
- `Vazirmatn-Bold.woff2`
- `Vazirmatn-ExtraBold.woff2`

بدون این فایل‌ها هم مشکلی نیست: مرورگر اول فونت نصب‌شده روی خود دستگاه،
بعد CDN و در نهایت Tahoma را استفاده می‌کند.
