# 🏹 شکارچی کلمات — بازی آموزش املای فارسی

بازی اکشنِ کلاس‌محور برای آموزش املای فارسی. دانش‌آموز با کمان به واژه‌ها شلیک می‌کند و
پس از هر پاسخ، **قاعدهٔ املایی، معنی و نمونهٔ آن واژه در جمله** روی صفحه می‌آید.
مناسب نمایش روی ویدئوپروژکتور و تخته هوشمند.

---

## اجرا

```bash
npm install
npm run dev        # اجرا روی http://localhost:5173
npm run build      # خروجی: dist/index.html
```

خروجی ساخت، **یک فایل HTML تک‌پارچه** است. آن را روی فلش بریزید و در هر مرورگری باز کنید؛
نه اینترنت لازم دارد و نه نصب. (تنها فونت وزیرمتن از اینترنت گرفته می‌شود و اگر نبود،
فونت فارسی سیستم جایگزین می‌شود.)

---

## چه چیزی در بازی هست

### ۶ سرزمین، ۲۴ مرحله

| سرزمین | موضوع املایی |
|---|---|
| 🌲 جنگل کلمات | س / ص / ث |
| 💎 غار بلورین حروف | ز / ض / ظ / ذ |
| ☁️ شهر معلق واژه‌ها | ت / ط و غ / ق |
| 🏰 قلعهٔ غلط‌نویس | ه / ح و واو معدوله (خوا/خا) |
| 🏜️ کویر طومارهای گمشده | گزار / گذار و نیم‌فاصله |
| 👑 جزیرهٔ استادان املا | تنوین نصب (اً) و آزمون همهٔ قاعده‌ها |

### ۷ حالت بازی

- **شکار کلمه** — املای درست را از میان گویچه‌های شناور پیدا کن.
- **تیراندازی به حرف** — جای خالی واژه را با حرف درست پر کن.
- **نجات کلمه** — قفل‌های املای غلط را بشکن تا واژهٔ طلایی آزاد شود.
- **شکار غلط املایی** — هیولا واژه را غلط نوشته؛ نوشتار درست را به او بزن.
- **املای شنیداری** — واژه خوانده می‌شود، نوشتار درستش را انتخاب کن.
- **حملهٔ زمان‌دار** — در زمان محدود، بیشترین پاسخ درست.
- **نبرد با غول غلط‌نویس** — نبرد چندمرحله‌ای با سپر رون‌ها و نفرین‌های پرتابی.

### بانک واژگان

۱۴۱ واژهٔ آماده در ۹ دستهٔ املایی، هر کدام با قاعده، معنی، نمونه در جمله و املاهای نادرست رایج.

---

## ابزارهای معلم

- **جلسهٔ کلاس** — فهرست دانش‌آموزان را یک‌بار وارد کنید. در «حالت نوبتی» پس از هر پاسخ،
  نوبت خودکار به نفر بعد می‌رسد و امتیاز به نام او ثبت می‌شود.
- **گردونهٔ نوبت** — انتخاب تصادفیِ عادلانه؛ کسانی که کمتر نوبت گرفته‌اند شانس بیشتری دارند.
- **گزارش کلاس** — کارنامهٔ هر دانش‌آموز (تعداد پاسخ درست، دقت، بهترین زنجیره، امتیاز) به‌همراه
  فهرست **واژه‌هایی که کلاس بیشتر در آن‌ها اشتباه کرده** — یعنی دقیقاً همان چیزی که باید
  جلسهٔ بعد دوباره کار شود. قابل چاپ یا ذخیره به‌صورت PDF.
- **واژه‌های معلم** — واژه‌های درس همین هفته را اضافه کنید تا در بازی بیایند.
  با گزینهٔ «فقط واژه‌های من»، بازی تنها از فهرست شما استفاده می‌کند.
  خروجی/ورودی JSON برای انتقال بین دستگاه‌ها.
- **تحلیل کلاسی** — بازی را وسط کار متوقف کنید و قاعده، معنی، جمله و پرسش‌های گفت‌وگوی
  همان واژه را روی پرده نشان دهید.
- **حالت ویدئوپروژکتور** — قلم درشت‌تر و کنتراست بالاتر برای دیده شدن از ته کلاس.
- **دانشنامهٔ املا** — همهٔ ۱۴۱ واژه با جست‌وجو، به‌همراه صفحهٔ قاعده و ترفندهای هر دسته.

همهٔ داده‌ها فقط روی همان دستگاه ذخیره می‌شوند. نه ثبت‌نامی لازم است، نه حسابی، و نه اینترنتی.

## کنترل‌ها

| کار | کلید |
|---|---|
| نشانه‌گیری | حرکت موس یا لمس صفحه |
| شلیک | رها کردن کلیک / لمس، یا `Space` |
| تغییر زاویه | `↑` و `↓` |
| تغییر قدرت | `→` و `←` |
| انتخاب نوع تیر | `۱` تا `۵` |
| توقف بازی | `Esc` |
| شنیدن دوبارهٔ واژه (حالت شنیداری) | `R` |

کمان‌نمای مسیر همیشه دیده می‌شود تا نشانه‌گیری برای بچه‌های کوچک‌تر هم آسان باشد.

## ساختار کد

```
src/
  data/wordBank.ts              بانک واژگان و قاعده‌های هر دسته
  engine/world.ts               دنیای مجازی ۱۲۸۰×۷۲۰ و تبدیل مختصات
  engine/scenery.ts             پس‌زمینه‌های پویا و لایه‌ای هر سرزمین
  engine/draw.ts                رسم گویچه‌ها، بلورها، هیولا، غول و کماندار
  services/SpellingContentAdapter.ts   انتخاب واژه بر پایهٔ دسته/پایه/دشواری
  services/WorldData.ts         سرزمین‌ها، مرحله‌ها، کمان‌ها و فروشگاه
  services/AudioService.ts      صداها (همه ساختهٔ Web Audio) و گفتار فارسی
  services/ClassSession.ts      فهرست کلاس، نوبت‌ها و آمار دانش‌آموزان
  services/Progress.ts          ذخیرهٔ پیشرفت بازیکن
  components/GameCanvas.tsx     موتور بازی و منطق هفت حالت
  components/*.tsx              نقشه، HUD و پنجره‌ها
```

**نکتهٔ فنی:** تمام منطق بازی در یک بوم ثابت ۱۲۸۰×۷۲۰ نوشته شده و هنگام رسم با نسبت درست
روی هر نمایشگری جای می‌گیرد؛ به همین دلیل چیدمان اهداف روی موبایل، لپ‌تاپ و
ویدئوپروژکتور یکسان می‌ماند و هیچ هدفی از کادر بیرون نمی‌زند.
