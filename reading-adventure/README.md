# چراغِ کاروانسرا — ابزارِ درک مطلبِ تعاملی

یک داستانِ تعاملیِ شاخه‌ای برای درسِ فارسیِ پایه‌های چهارم تا ششم. دانش‌آموز متن را می‌خواند،
سرِ هر صحنه تصمیم می‌گیرد، و تصمیمش مسیر و پایانِ داستان را عوض می‌کند.

فایل `index.html` کاملاً خودبسنده است: نه بیلد لازم دارد، نه پکیج، نه بک‌اند.
تنها چیزی که از بیرون می‌گیرد، دو قلمِ فارسی از Google Fonts است.

---

## ایدهٔ اصلی: «قفلِ درک»

مشکلِ همیشگیِ داستان‌های تعاملی این است که بچه می‌تواند متن را **نخواند** و باز هم انتخاب کند.
اینجا هر انتخاب طوری نوشته شده که **جوابش فقط از داخلِ متن درمی‌آید**؛ حدس و سلیقه کار نمی‌کند.

سؤال‌ها روی چهار سطحِ درک مطلبِ چارچوب PIRLS توزیع شده‌اند (همان چارچوبی که آزمونِ
بین‌المللیِ خواندن برای پایهٔ چهارم استفاده می‌کند):

| سطح | چه چیزی را تمرین می‌دهد | نمونه در همین داستان |
|---|---|---|
| ۱ | بازیابیِ اطلاعاتِ صریح | کدام فانوس را برداری؟ (جواب مستقیم در متن است) |
| ۲ | استنباطِ مستقیم | روغن کجا رفته؟ (سه جمله را باید کنارِ هم گذاشت) |
| ۳ | تفسیر و یکپارچه‌سازی | چرا نگار راستش را نمی‌گوید؟ (از روی نشانه‌ها) |
| ۴ | ارزیابی و قضاوت | چه می‌کنی؟ (جوابِ غلط ندارد، ولی پیامد دارد) |

سه رفتارِ کلیدی که ابزار را از یک آزمونِ چهارگزینه‌ای جدا می‌کند:

1. **جوابِ غلط، شکست نیست.** پیامِ «برگرد به متن» می‌آید و **همان جملهٔ شاهد در متن روشن می‌شود**.
   یعنی به بچه یاد می‌دهد جواب را از متن پیدا کند، نه از حافظه.
2. **دفترچهٔ سرنخ.** دانش‌آموز می‌تواند روی هر جمله ضربه بزند تا در دفترچه ذخیره شود؛
   تمرینِ پنهانِ «خوانشِ فعال» و جدا کردنِ اطلاعاتِ مهم از فرعی.
3. **کارنامهٔ پایان.** در انتهای بازی معلوم می‌شود بچه در کدام سطحِ درک مطلب قوی بوده و کجا لنگیده.

## ساختارِ شاخه‌ای

شاخه‌ها به‌جای انفجارِ نمایی (۳ گزینه × ۷ صحنه = ۲۱۸۷ مسیر) با الگوی **گلوگاهی** ساخته شده‌اند:
داستان سرِ صحنهٔ ۳ به دو مسیرِ واقعاً متفاوت باز می‌شود و در انبارِ ته ده دوباره به هم می‌رسد.
آنچه پایان را تعیین می‌کند، **حافظهٔ پنهانِ** بازی است، نه مسیر:

- `moral` — تصمیمِ اخلاقیِ صحنهٔ آخر
- `trust` — اعتمادی که نگار به تو پیدا کرده
- تعدادِ پاسخ‌های درست در اولین تلاش

نتیجه: چهار پایانِ واقعاً متفاوت، با حجمِ نوشتاریِ قابلِ نگه‌داری.

## تفاوتِ پایه‌ها

متنِ داستان برای هر سه پایه یکی است؛ آنچه فرق می‌کند **میزانِ داربستِ کمکی** است:

| پایه | واژه‌نامه | راهنمای متن بعد از جوابِ غلط |
|---|---|---|
| چهارم | فهرستِ معنیِ واژه‌ها همیشه زیرِ متن باز است | بلافاصله |
| پنجم | واژه‌ها خط‌چین دارند؛ با ضربه معنی می‌آید | بلافاصله |
| ششم | خط‌چین برداشته می‌شود؛ با ضربه معنی می‌آید | فقط بعد از دومین اشتباه |

## حالتِ کلاس

دکمهٔ «حالتِ کلاس» در نوارِ بالا برای ویدئوپروژکتور است:

- اندازهٔ قلم و عرضِ ستون بزرگ‌تر می‌شود
- برچسبِ سطحِ درک مطلبِ هر سؤال نمایان می‌شود تا معلم بداند دارد چه چیزی را تمرین می‌دهد
- کلیدهای `۱` `۲` `۳` گزینه‌ها را انتخاب می‌کنند و `Enter` صحنه را جلو می‌برد
  (معلم می‌تواند رأی‌گیریِ دستی کند و بعد کلید بزند)

## گذاشتن در سایت

فایل خودبسنده است، پس ساده‌ترین راه:

```
public/reading-adventure/index.html
```

و در اکسپرس:

```js
app.use("/reading-adventure", express.static(path.join(__dirname, "public/reading-adventure")));
```

بعد در پنلِ دانش‌آموز و پنلِ معلم، لینک یا `iframe`:

```html
<iframe src="/reading-adventure/" style="width:100%;height:100vh;border:0" title="چراغ کاروانسرا"></iframe>
```

اگر می‌خواهی پایه از روی پروفایلِ دانش‌آموز تعیین شود، با کوئری‌استرینگ:
`/reading-adventure/?grade=4` — چند خط کد لازم دارد که هنوز اضافه نشده؛ بگو تا اضافه کنم.

## اضافه کردنِ داستانِ تازه

موتورِ بازی هیچ چیزی دربارهٔ این داستان نمی‌داند. کافی است یک شیء با همین ساختار بسازی.
دو بلوکِ `<script>` در `index.html` عمداً از هم جدا هستند: اولی فقط **داده** است و دومی فقط
**موتور**. بلوکِ داده را می‌شود بی‌هیچ تغییری در موتور به فایلِ جدا، دیتابیس یا API منتقل کرد.

```js
const STORY = {
  id: "charagh",
  title: "چراغِ کاروانسرا",
  start: "s1",

  scenes: {
    s1: {
      place: "دروازهٔ دِه‌بالا · شب",     // بالای صحنه نشان داده می‌شود

      // هر رشته یک جمله است. "|" یعنی پاراگرافِ تازه.
      // شمارهٔ جمله‌ها (برای ev) فقط روی جمله‌ها شمرده می‌شود و "|" را نمی‌شمارد.
      text: ["جملهٔ صفر.", "جملهٔ یک.", "|", "جملهٔ دو."],

      gloss: { "کاهگل": "گِلی که با کاه مخلوط می‌کنند" },   // واژه‌نامهٔ همین صحنه

      level: 2,                       // ۰ تصمیمِ مسیر · ۱ تا ۳ نمره‌دار · ۴ ارزیابی
      question: "به‌نظرت روغن کجا رفته است؟",
      note: "متنِ اختیاری بالای گزینه‌ها",

      choices: [
        { t: "متنِ گزینه",
          ok: true,                   // فقط یکی از گزینه‌ها در سطحِ ۱ تا ۳
          ev: [1, 2],                 // شمارهٔ جمله‌هایی که شاهدِ این جواب‌اند
          why: "توضیحی که بعد از انتخاب نشان داده می‌شود",
          next: "s4a",                // اختیاری: مقصدِ مخصوصِ همین گزینه
          vars: { moral: "together" } // اختیاری: تغییرِ حافظهٔ پنهان
        }
      ],

      clue: "جمله‌ای که بعد از جوابِ درست به دفترچه اضافه می‌شود",
      next: "s3"                      // مقصدِ پیش‌فرض؛ "END" یعنی پایانِ داستان
    }
  },

  // از بالا به پایین بررسی می‌شوند؛ اولین قاعده‌ای که درست باشد برنده است
  endingRules: [
    { when: { moral: "together", minCorrect: 3 }, id: "gold" },
    { when: {},                                   id: "good" }
  ],

  endings: {
    gold: { badge: "پایانِ ۱ از ۴ · بهترین پایان", title: "چراغِ ده",
            text: ["پاراگرافِ اول.", "پاراگرافِ دوم."] }
  }
};
```

شرط‌های مجاز در `when`: `moral` (تساوی)، `minCorrect` (حداقل پاسخِ درست در اولین تلاش)،
`minTrust` (حداقل مقدارِ `trust`). شرطِ خالی `{}` همیشه درست است، پس آخرین قاعده را
خالی بگذار تا همیشه یک پایان پیدا شود.

مقدارِ `TOTAL_STEPS` در بالای موتور، تعدادِ صحنه‌های یک مسیرِ کامل است و فقط برای
پُر شدنِ فانوسِ پیشرفت استفاده می‌شود.

### قواعدی که موقعِ نوشتنِ داستانِ تازه رعایت کن

- هر صحنه **۸۰ تا ۱۵۰ کلمه**. بیشتر از این، بچهٔ ۹ ساله اسکرول می‌کند و رد می‌شود.
- هر گزینهٔ غلط باید **دلیلِ غلط بودنش در متن باشد**، نه در دانشِ عمومی. `why` باید
  دقیقاً به همان جمله ارجاع بدهد.
- `ev` را حتماً پر کن؛ همین است که «برگرد به متن» را از یک تذکرِ خالی به آموزش تبدیل می‌کند.
- در سطحِ ۴ هیچ گزینه‌ای `ok` نگیرد. جوابِ غلط نداریم، فقط پیامد داریم.
- سرِ دوراهیِ اصلی `level: 0` بگذار و برای هر گزینه `next` جدا بده.

## چیزهایی که هنوز ساخته نشده‌اند

- ذخیرهٔ وضعیت (بچه وسطِ داستان ببندد و بعداً ادامه بدهد)
- گزارشِ معلم از عملکردِ کلاس
- صداگذاری و تصویرِ صحنه‌ها
- بانکِ چند داستان و صفحهٔ انتخابِ داستان
