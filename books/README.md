# کتاب‌های درسی

فایل PDF کتاب‌ها اینجا نگه داشته می‌شوند. سرور آن‌ها را روی آدرس
`/books/...` سرو می‌کند.

## چیدمان

```
books/
├── paye3/          کلاس سوم
│   ├── riazi-3.pdf   ریاضی سوم (۱۵۳ صفحه)
│   └── olum-3.pdf    علوم تجربی سوم (۱۲۹ صفحه)
├── paye6/          کلاس ششم
│   ├── riazi-6.pdf   ریاضی ششم (۱۵۲ صفحه)
│   └── olum-6.pdf    علوم تجربی ششم (۱۱۲ صفحه)
├── scan-14-safhe.pdf   اسکن ۱۴ صفحه‌ای — محتوایش مشخص نیست
└── scan-30-safhe.pdf   اسکن ۳۰ صفحه‌ای — محتوایش مشخص نیست
```

دو فایل اسکن‌شده لایه‌ی متنی ندارند و از روی فایل نمی‌شود فهمید چه کتابی‌اند.
اگر می‌دانی چه هستند، اسمشان را عوض کن (مثلاً `paye3/riazi-3-fasl1.pdf`).
